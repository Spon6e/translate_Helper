Данное приложение позволяет переводить с русского на английский при написании кода. Это полезно, когда ты знаешь для чего создаешь переменную, функцию или класс, но не знаешь перевод на английский язык.
Так же данное приложение работает как поисковик для ответов с использованием Алисы AI, но без Api ключа.
